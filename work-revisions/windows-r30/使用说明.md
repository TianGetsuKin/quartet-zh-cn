# 《四重奏》简体中文补丁 · Windows r30

适配 Steam Windows 版 **1.5.20261124**（Build 26908524）。可在游戏设置页右下角核对版本号。原生 Linux 和原生 Steam Deck 的 l15 仍仅适用于旧游戏版本 1.5.20260912。新版原生 Linux 尚未适配，Windows r30 也尚未在 Steam Deck／Proton 上验证。

[官方游戏公告](https://store.steampowered.com/news/app/1307960/view/1850460852983911)

## 安装与升级

1. 保存并退出游戏。在 Steam 库右击《四重奏》，选择“管理 → 浏览本地文件”，找到 Quartet.exe。
2. 从旧游戏版本升级的玩家请先让 Steam 更新完成，再在“属性 → 已安装文件”验证游戏文件完整性。可将原有汉化的两个额外文件 QuartetRecentItems.dll、QuartetZhLanguage.dll 一起移到游戏目录外备份。
3. 将“文件清单.json”中原版已有的同名文件备份到游戏目录外。完整解压 ZIP，打开“覆盖到游戏目录”，把里面的文件和 Quartet_Data 文件夹一起复制到 Quartet.exe 所在目录，合并并覆盖。
4. 启动游戏，在“设置 → 游戏 → 语言”选择“简体中文”。

## 本次适配

r30 保留新版利甘蒂教学战的官方剧情判断，移除了旧补丁对此战的额外判断。序章首领沿用新版的虚弱姿态资源。保留原有中文、最近获得、装备比较定位和商店确认选项居中等改动。

## 还原

退出游戏，将两个汉化附加 DLL（QuartetRecentItems.dll 和 QuartetZhLanguage.dll）移出游戏目录。恢复同一游戏版本的原文件备份，或在 Steam 验证游戏文件完整性。压缩包不含存档或个人设置。

## 验证范围

已核对新版剧情字节码、Unity 资源、Windows DLL 加载、语言和装备菜单逻辑，并在独立目录校验覆盖安装和还原。利甘蒂实战、首领动画和新版本的游戏内画面仍待实机确认。字体许可见 OFL.txt。
